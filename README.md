# ORBIT® — Sitio web

Ideas en movimiento. Ideas in motion.

Sitio estático (HTML/CSS/JS, sin build) publicado con GitHub Pages.

## Páginas
- `index.html` — Home
- `productos.html` — Catálogo con filtro por familia
- `producto.html?id=ob-006` — Ficha de producto (se arma desde el catálogo)
- `nosotros.html` — Marca, manifiesto y contacto

## Editar productos, precios y pagos
Todo está en `assets/js/products.js`. Para activar la compra, pegá en `checkout` el link de pago de tu plataforma (Lemon Squeezy, Gumroad, Stripe Payment Links, Hotmart…).


Manual de marca: https://mariasicco.github.io/orbit-brand-manual/
